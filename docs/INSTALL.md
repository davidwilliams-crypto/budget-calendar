## Install Budget Calendar

You need a Windows 10 or Windows 11 PC. You don't need an administrator password, an account or an internet connection to use it.

1. **Download** `BudgetCalendar-{VERSION}-setup.exe` from the **Assets** list at the bottom of this page.
2. **Open the file** from your Downloads folder.
   - Windows may show a blue box titled **"Windows protected your PC"**. This happens with new programs that few people have downloaded yet. Click **More info**. The *Publisher* line should show a name, not *Unknown publisher*. If it does, click **Run anyway**.
   - If the *Publisher* line says *Unknown publisher*, stop: that file did not come from this page. Delete it and download it again from here.
3. Click **Next**, then **Install**.
4. On the last screen, leave **Start Budget Calendar now** ticked. Untick **Put a shortcut on my desktop** if you don't want one. Then click **Finish**.

Later you can open Budget Calendar from the **Start menu**. Double-clicking a `.bgt` budget file opens it too.

## Your first budget

1. Click **Start a new budget…**, pick a folder (your *Documents* folder is a good choice), type a name and click **Save**.
2. Click **New payment**, choose **Income** and add your pay. Choose how often it repeats, for example every 2 weeks.
3. Add your regular bills the same way, choosing **Expense**: rent or mortgage, loans, phone, insurance. Type the amount without a minus sign.
4. Set today's bank balance. Right-click today's balance at the bottom of today's square and choose **Edit balance**.

The calendar now shows your expected balance on every future day. Each month's lowest day is marked, so you can see a tight spot coming.

Press **Ctrl+S** to save. If you forget, Budget Calendar asks before closing, and keeps a protected copy if the PC crashes.

## Keeping your budget safe

- Your budget is a single `.bgt` file on your PC. Nothing is sent anywhere unless you choose **File → Shared budget…**.
- Back up that file the way you back up your photos and documents, for example in OneDrive or on a USB stick.
- **File → Restore previous version…** brings back an earlier save if you make a mistake.

## Updating and removing

- **To update**, download the newer setup file and run it the same way. Your budgets are not touched. Close Budget Calendar first; the installer reminds you if it is open.
- **To remove**, use **Settings → Apps → Installed apps → Budget Calendar → Uninstall**. Only the program is removed. Your budget files stay where you saved them.

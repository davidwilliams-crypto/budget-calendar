Overview

The Budget Calendar is designed to help you easily comprehend your budget. The key feature is allowing you to see the shortfalls of your budget on day by day basis.

The main window contains a calendar view of a budget month with income/expense transactions in the calendar cells.

These are the parts of the main window on the screen shot above:

·         Month Selector and Quick Stats. This pane contains the initial and closing balances, actual income and expenses totals.

·         Forecast graph. Each bar represents average daily balance (by default) for the future month (planned, not actual, if that was an actual amount I would not be doing this). You can change the type of the graph by clicking on the graph's title and selecting a different type, or by clicking on a quick stats item.

·         Brief Summary. Split of the payments of the current month. It shows all payments which are more or equal to 5% of the total income, to see all payments click on Full Summary. The “+/-“ column shows the difference between planned and actual values. Put mouse pointer on top of a summary item – appropriate cells in the calendar will be highlighted. If you click on a name of a transaction or a category the selected string will be applied as the filter.

·        Filter. Type your filter in. The transactions that do not match the entered filter won’t be displayed in the calendar view. The stats will be filtered too. See Filter expression for details.

·         Notes. Simple text field that lets you add notes.

·         Calendar cells. Each cell has:

·         The day of the month in the left top corner. The “…” after the number indicate that there is a note attached to this day. The ‘ sign indicates that there were transactions removed from this day – the cells context menu can be used to restore them.

·         This day’s transaction(s), each transaction has:

·         Image (optional)

·         Description start with the “…” then there is a note attached to this transaction

·         Amount – the ‘ sign after the number indicates that this amount was adjusted, the * sign indicates that this is the last transaction of this payment.

·         The bottom bar is the day's ending balance:

·         The pink bar indicates the maximum balance of the month.

·         The darker blue indicates the minimum balance of the month.

·         When the pointer hovers over the bar you will see the sums of day’s income and expenses (Day’s In and Out).

Payments vs. Transactions

This budget application deals with payments and transactions. A payment consists of one or more transactions. A transaction is a simple money operation that adds or subtracts some amount from you balance on a particular date and it belongs to a payment. There can't be two transactions for the same payment in one cell. When you create a payment you specify the following for the payment:

  • The scheduled date of the first transaction;
  • How often transactions occur;
  • The end date, or number of payments, or indefinite, or until a loan is paid off.

Based on this information the transactions are added into the calendar view.

Adding a payment
  • Calendar View: Right-click on a cell heading (day number bar) or anywhere else other than transactions and click on Add a new payment.
  • "List of All Payments" window: Right-click and click on Add a new payment.

Either of these actions opens the Payment Editing window. To create a new payment based on an existing one, right-click the payment and select Duplicate payment.

Payment Editing

When you create a new payment of modify an existing one (by double-clicking on a transaction or a payment) you see this window:

Field

Description

Description

A brief description of the payment. If the description is too long (and looks bad in the calendar cells) you can put ';' in the text. Text before the ';' is put in the calendar view. In the list of all payments the whole text is shown.

Category

A category to which this payment belongs. This name will be used for statistics calculation and reports

Amount

The regular amount for this payment. Use Expense and Income radio buttons to specify what it is. If you hover the mouse pointer over this field a balloon text with a suggested amount will show. The suggested amount is an average of all transactions of this payment in the last 6 months.

Expense/Income

Convenience check boxes.

Disabled

Check this box if you want to disable this payment. Transactions for this payment will still appear in the calendar cells but will be grayed out and not used in the balance calculations. This option is useful when you want to try a different payment schedule without changing too much stuff.

Start Date

The first transaction day of this payment.

End

The end date of the payment. Use the radio button to specify this value.

Grace Period

Number of grace days for transactions. When you hover over a transaction the “valid” days for this transaction will be highlighted.

Pay Every

How often transactions are added into the calendar. The “Nth Weekday of a month” option is a special one. When this option is selected the number box is disabled – because as the name states this is done every month. Let’s say you have a payment that goes on the first Monday of a month. You create a new payment on the first Monday of a month, and check this option. From now on Budget Calendar will place recurring transaction on the First Monday of the following month(s).

Amount paid

This is useful if you try to payout a loan without fixed payment amount.

Business Days Only and Early Pay

Check this option if the specified payment transactions happen only during business days (i.e. no Saturdays and Sundays).  The transactions will be moved to the next Monday unless the Early Pay is set, then they are moved to the previous Friday.

Tentative

Tentative transactions will automatically slide to the current date if the current date is in the transaction’s pay period – provided that there are no adjustments in this pay period. Pay period is calculated based on the payment’s start date and the ‘Pay every:’ data. For example if you set up Pay Every 2 weeks starting on the 2nd of a month, indefinitely. The payment periods will be: 2nd to 15th, 16th to 29th and etc. The grace period days are not used directly – the pay period defines the “grace period days”. In our example it is 14 days.

If there were no adjustments in the pay periods before the current pay period – there will be no transactions in these periods. (simply removed).

If you remove a tentative transaction from the current or a future pay period, you will be able to restore it by using the “Restore…” menu item on the current day or on the future period’s first day – provided you don’t have adjustments in that period.

This type of transaction is helpful when you write cheques by hand and not sure when they get cashed-in.

Sticky

Override transaction's default (regular) amount with the last adjustment in the calendar before this transaction's date, if available. This is useful when future transactions' amounts tend to stick around. Using this flag with Disabled allows to emulate a balance of some other continues amounts.

Mark as

Convenience flags

Image

The image for the calendar view to place beside the transaction text. Click on the image button to select an image. Quick pick images may be displayed beside the image. You can click on a quick pick image to use it. Quick pick images are displayed based on the words you put in the description and category.

Deleting a payment

Click on List of All Payments in the File menu. In The List of all Payments window, find the required payment in the table. Right-click the payment and click on Delete payment. You can open the Edit dialog on a transaction and click on Delete button.

Moving a transaction

Right-click on a transaction and click on Move Transaction item. In the Date Picker window select the required date to which you want to move the transaction. If you need to move a transaction within the currently visible month, you can drag the transaction to the new date. Moved transactions have the ' symbol as the suffix.

Adjusting a transaction amount

Double-click on the amount text of the transaction. In the New Amount window enter the new amount and press Enter. Transactions with adjusted amounts have the ' symbol as the suffix.

Restoring a transaction

If you deleted a transaction on a particular date or moved it to some other day and would like to have it back, right-click on the cell heading of the date that held the transaction and click on Restore 'your transaction name here'.  The days that have restorable transactions have a ‘ symbol as the day number’s suffix. Important: Please note that if you have moved a transaction to another day the “undo” will not be performed, so you may end-up with multiple transactions.

Balance adjustments

If you need to adjust the balance on a particular day, right-click on the balance bar of the required date and click on Adjust balance. In the Balance Adjustment window enter the required amount and press Enter. Adjusted balance will have a ' symbol as the suffix. You can enter a simple mathematical formula in the adjust balance field. For example, you can enter "1234 – 23/2".

Removing balance adjustment

Right-click on the balance bar that has an adjustment and select Remove Adjustment.

Altering a payment's regular amount on a date

Sometimes there is a need to change the amount of all transactions of a payment after a certain date. Right-click on a transaction, select alter transactions from... in the menu. Confirm your operation in the shown confirmation dialog. The payment will be split into two. The original payment will get its end date adjusted to one day before the altering date. The payment’s amount will stay unchanged. The new payment transactions start on the date of the split. The payment Editing dialog for the new payment will be shown to let you adjust the payment’s details.

Filter expression

You can apply filter to Calendar View or All payments dialog.  Here is what you can put in:

·        A whole or a part of a transaction name

·        >n, <n or =n where n is a number, works as amount filter

·        Start your filter expression with a '|' to set 'OR' search mode

·        Use '_' where you need a filter for a space

·        Use cat:substring to filter by categories only, desc:substring – by description only, date:datesubstring – by date only

Examples:

cat:utils <-100

Will filter all transactions that belong to the utils category with the amount less that -100.

Adding your own icons

Put your images into the C:\Program File\MiShellSoft\Budget\app\images\ directory. On the next run the new icons will be available in the icon selection window. The default images are GIFs and PNGs with the size of 18x18. It is recommended to use images with transparency.

Using Excel Reports

When you need to save an open Excel Report for a future reference, please make sure that you do the following:
In Excel, open the File menu, click on Save as... item. The Save as dialog will pop up. Set the Save as type: to Microsoft Excel Workbook. Change the file name, if required, from out to your preference, for example April2005Budget, then click the Save button.
